## 保留的原分析与修复

- SQL 01—05分别处理平台、地区、评价、卖家和交运金额。早期补充查询保存在 `sql/exploratory/`，其中部分与05重复，不必为生成主结果再运行。
- 原导入文件名称称八张表，内容包含九张。首次整理移除了清表和全局设置操作，限定全新数据库首次导入。地区查询修正了 `peroid/period` 拼写，并补齐相邻语句的分号。
- 三份 `export_*.sql` 从原分析查询保留卖家画像、交运及金额的订单级去重逻辑。导出脚本填补手工另存查询结果的步骤。
- 原统计代码补齐 `.py` 扩展名。首次运行的环境和失败记录保存在[历史核验记录](validation.md)，不把静态检查等同数据库执行。
- 当前脚本将一般输入有效性检查和固定数据版本检查分开，固定基准通过 `OLIST_VERIFY_REFERENCE=1` 启用。指标和模型定义见[方法文档](methodology.md)。
